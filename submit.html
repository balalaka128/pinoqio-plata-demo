Team Pinoqio · Plata track

A judge that learns from the expert

Learns the expert's unwritten rules from the labeled training set, writes them down as a per-topic rulebook with priorities and evidence, and grades new conversations with those rules. Any broken rule: bad.

Run

python3 src/prepare_inputs.py --train <train.csv> --test <test.csv> --out-dir in
docker build -t pinoqio-judge .
docker run --rm -e GEMINI_API_KEY -v "$PWD/in:/input" -v "$PWD/artifacts:/artifacts" pinoqio-judge adapt
docker run --rm -e GEMINI_API_KEY -v "$PWD/in:/input" -v "$PWD/artifacts:/artifacts" -v "$PWD/out:/output" pinoqio-judge eval
  • adapt writes the jury explanation to /artifacts/explanation.md, plus rulebook.json and the exact per-topic prompts.
  • Rate limit: 14 requests/min by default (Gemma free tier). With a paid key set JUDGE_RPM higher to finish faster.
  • Key from GEMINI_API_KEY, GEMINI_API_KEY_JUDGE or GOOGLE_API_KEY.
